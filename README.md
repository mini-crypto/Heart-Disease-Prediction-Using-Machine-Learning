# Heart Disease Prediction Using Machine Learning

## Overview

This project predicts the likelihood of heart disease using patient health information. A Logistic Regression model is trained to classify whether a patient is at risk of heart disease.

## Objective

- Perform Exploratory Data Analysis (EDA)
- Clean and preprocess the dataset
- Train a classification model
- Evaluate performance using multiple metrics
- Identify important factors affecting heart disease risk

## Dataset

Heart Disease UCI Dataset

Target Variable:

- 0 = No Heart Disease
- 1 = Heart Disease

## Technologies Used

- Python
- Pandas
- NumPy
- Seaborn
- Matplotlib
- Scikit-learn

## Workflow

1. Load dataset
2. Data cleaning
3. Exploratory Data Analysis
4. Feature selection
5. Train-test split
6. Model training
7. Model evaluation
8. Feature importance analysis

## Machine Learning Model

- Logistic Regression

## Evaluation Metrics

- Accuracy
- Confusion Matrix
- ROC Curve
- ROC-AUC Score
- Precision
- Recall
- F1-Score

## Key Findings

The model successfully classified patients based on health indicators and identified the most influential features associated with heart disease risk.
